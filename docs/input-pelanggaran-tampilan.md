# Tampilan konfigurasi pelanggaran

Panel konfigurasi input massal memakai label yang terbaca, jarak yang konsisten,
dan tombol buka/tutup yang bisa dioperasikan dengan keyboard.

Jenis pelanggaran yang sering dicatat ditampilkan sebagai baris selebar panel.
Setiap baris menampilkan nama, label poin, dan tanda pilihan aktif. Nama yang
panjang dapat membungkus; rincian lengkap tersedia pada ringkasan pilihan dan
dialog semua pelanggaran. Pilihan tetap menggunakan kode pelanggaran yang sama.

Dialog menyediakan pencarian nama atau kode dan pengelompokan Ringan, Sedang,
serta Berat. Pencarian tidak langsung membuka keyboard di ponsel. Tanggal kejadian
dan keterangan opsional memakai label terpisah dari placeholder.

Komponen `ViolationConfigurationFields` memisahkan tampilan pelanggaran dari
konfigurasi mode input lainnya. Perubahan ini tidak mengubah poin, penyimpanan,
atau pengiriman laporan WhatsApp.

Pratinjau dengan data contoh diperiksa pada lebar 320, 390, dan 1440 piksel,
termasuk mode gelap, pilihan aktif, serta pencarian dalam dialog.
